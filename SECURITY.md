# Security Policy

## Reporting a vulnerability

Please don't report security vulnerabilities in public issues, pull requests or discussions.

Report them privately through GitHub instead: open the repository's **Security** tab and click **Report a vulnerability**. Only the maintainers can see the report.

Please include:

- What the problem is and what an attacker could do with it.
- Steps to reproduce, including the browser and Beyond20 version.
- Any proof of concept, logs or screenshots that help.

Beyond20 is maintained by volunteers, so responses are best effort. We'll acknowledge your report, keep you updated while we work on a fix, and credit you in the release notes if you'd like.

## Supported versions

Only the latest release, as published on the Chrome Web Store, Firefox Add-ons and Edge Add-ons, gets security fixes. Store installs update automatically.

## Scope

In scope:

- The Beyond20 browser extension in this repository.
- The Beyond20 Foundry VTT module in `FVTT-module/`.
- How Beyond20 handles your settings, including Discord channel secrets.

Out of scope:

- Vulnerabilities in D&D Beyond, Roll20, Foundry VTT, Discord or other sites Beyond20 connects to. Please report those to the site's owner.
- Issues that need an attacker to already control your browser or computer.
